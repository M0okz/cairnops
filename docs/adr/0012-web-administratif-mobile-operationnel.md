# Centrer l'administration sur le Web et les opérations sur le mobile

L'interface Web expose l'ensemble de l'administration de CairnOps, tandis que les compagnons iOS et Android garantissent la consultation et les actions opérationnelles complètes sur les Cibles, Incidents et Événements. Le mobile peut proposer quelques raccourcis sûrs, comme suspendre une Source ou démarrer une maintenance immédiate, sans dupliquer les configurations complexes ; le partage du même état promet ainsi une cohérence des données et des opérations, pas une parité artificielle de chaque écran.
