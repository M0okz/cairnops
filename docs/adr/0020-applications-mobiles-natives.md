# Développer deux applications mobiles natives

Le compagnon iOS utilise SwiftUI et le compagnon Android Jetpack Compose ; ils partagent le contrat d'API et le modèle conceptuel, mais aucun framework d'interface commun. Ce coût supplémentaire privilégie l'intégration aux notifications et au stockage sécurisé, les conventions propres à chaque plateforme et un niveau de finition visuelle inspirant confiance, tandis que la logique autoritative demeure sur le serveur et que les applications restent des projections opérationnelles fines.
