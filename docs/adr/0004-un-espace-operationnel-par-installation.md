# Limiter chaque installation à un Espace opérationnel

Une installation CairnOps héberge un seul Espace opérationnel pouvant réunir plusieurs utilisateurs et appareils. L'isolation de deux organisations ou environnements exige deux installations distinctes : CairnOps renonce ainsi au multi-tenant interne afin de simplifier durablement les autorisations, le stockage, les événements et les flux temps réel dans son modèle self-hosted.
