# Ouvrir CairnOps sous AGPL-3.0

Le serveur, le worker, l'interface Web, les applications mobiles, le protocole et l'implémentation du Relais Push sont publics sous AGPL-3.0, afin que les dérivés distribués ou exploités comme services partagent leurs modifications. Les applications officielles sont initialement gratuites sur les stores et la V1 ne sépare pas ses fonctions entre éditions communautaire et payante, même si le projet opère le Relais Push utilisé par les builds officiels.
