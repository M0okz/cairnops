# Politique de sécurité

## Versions prises en charge

CairnOps n'a pas encore publié de version exécutable. Cette politique sera
précisée avant la première version publique.

## Signaler une vulnérabilité

Ne publiez pas une vulnérabilité dans une issue publique. Utilisez le canal
privé **Security → Report a vulnerability** du dépôt GitHub :

https://github.com/M0okz/cairnops/security/advisories/new

Indiquez, si possible, le composant concerné, les conditions de reproduction,
l'impact observé et une piste de correction. Un accusé de réception et un cadre
de divulgation coordonnée seront convenus avec le rapporteur.

Les problèmes de sécurité sans caractère confidentiel peuvent être signalés
avec le gabarit d'issue standard.
